# Virtual Wimbledon Experience Simulator
This is a tennis game that uses Android smartphones as controllers. Heavily inspired by the tennis minigame from Wii Sports.

## How-to
Install Swiggity from Google Play Store on your Android phone, and type the room id that is shown in the game. Then enjoy!
The player will follow the ball automatically, and you just need to swing! There are two types of swing: soft and hard.
